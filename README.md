# UI-UX-Experiment6

## Aim:
To help users track their moods and manage stress through daily check-ins.
## Algorithm:
Start the app and open the Daily Check-in screen.

Display mood options to the user.

User selects a mood and optionally adds a note.

Save the mood and note to the system.

Generate and show a suitable suggestion (e.g., breathing exercise).

User completes the suggested activity.

Update insights and display trends when the user views them.
